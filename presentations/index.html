How to add another presentation

Two steps, both in the browser. No software, no command line.

  1. Upload the files. In your repository, open presentations/files/ → Add file → Upload files. Add the .pdf (what people view) and the .pptx (what you edit). Give them the same short lowercase name with no spaces, e.g. advising-track.pdf and advising-track.pptx.
  2. Add one entry to the list. Open presentations/index.html, click the pencil, and add a block to DECKS near the bottom:
{
  id:    'advising-track',
  tier:  'Tier 2',
  name:  'Advising & Student-Facing Track',
  slides: 24,
  time:  '90 minutes',
  desc:  'One sentence about who it is for.'
},

Commit, wait about a minute, refresh. It appears in the list.

To get a PDF from PowerPoint: File → Save a Copy (or Export) → choose PDF. Keep the .pptx too — that is the one you can still edit, and the one with the Morph animations.
