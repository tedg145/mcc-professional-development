How to add a presentation, or a whole new category

Everything below happens in the browser. No software, no command line.

  1. Upload the files. In the repository, open presentations/files/ → Add file → Upload files. Add the .pdf (what people view) and the .pptx (what you edit). Give both the same short lowercase name with no spaces, e.g. assignment-redesign.pdf and assignment-redesign.pptx. Wait for the file list to appear before clicking Commit — large files take a few seconds to upload.
  2. Add one entry. Open presentations/index.html, click the pencil, and drop a block into the right category's decks list near the bottom:
{
  id:    'assignment-redesign',
  tier:  'Tier 2',
  name:  'Redesigning One Assignment',
  slides: 22,
  time:  '90 minutes',
  desc:  'One sentence about who it is for.'
},

To add a whole new category — Advising, Leadership, Adjuncts — copy a category block:

{
  id:    'advising',
  name:  'Advising',
  who:   'Student-facing staff and early-alert teams.',
  decks: [ ]
},

Commit, wait about a minute, refresh. An empty category shows a friendly placeholder until you add the first deck to it.

Getting a PDF out of PowerPoint: File → Export (or Save a Copy) → choose PDF. Keep the .pptx too — that's the editable one, and the one carrying the Morph animations a PDF can't hold.
