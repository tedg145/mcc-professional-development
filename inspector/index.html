▶ Teaching notes — how to run this in a session

The opening that works

Do not explain metadata first. Ask one person to drop in a photo they took on their phone, on their own screen, and read the location out loud. Then explain. The order matters — the concept lands in about four seconds once they have seen their own coordinates, and not before.

The four questions to ask

  • Who does this file say made it? Office documents keep the original author and the last person to save, and they are often different people.
  • When does it say it was made? Compare the internal dates to the story the document tells. A brief created three days after the event it describes is a question worth asking.
  • What made it? The producing software reveals the path a file took — scanned, exported, converted, or edited.
  • What is still in there that you did not mean to send? Tracked changes, comments, embedded files, earlier saved revisions.

The points worth making out loud

  • A screenshot of a document is not the document. It is clean, which is sometimes what you want and sometimes destroys the thing that mattered.
  • Accepting all tracked changes is not removing them. Use the document inspector in Word, or produce a PDF.
  • Producing a PDF is not automatically safe. A PDF saved repeatedly can carry earlier revisions of its own content inside the same file.
  • Metadata cuts both ways. It is a disclosure risk on the way out and evidence on the way in. The same field that embarrasses you can authenticate a timeline.

A five-minute exercise

Hand out the sample files above. Ask each table to answer: if this file arrived in discovery, what is the first question you would ask about it? Then have them compare answers. Tables reliably find different things, which is the actual lesson — one person reading a file is not a review.

Where it fits

This pairs with the Understanding Metadata visual aid and with the evidence and e-discovery portion of the courtroom material. It also sets up the redaction discussion, because both are the same underlying idea: what you can see is not all that is there.

If you want to push it further

Use the Strip metadata button on a photo, download the cleaned copy, then drop that copy straight back in. The room watches the fields disappear. Teaching the fix immediately after the problem is what makes it stick.
