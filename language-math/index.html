Central idea

Is language
mathematical?

Human language is not literally mathematics — but it has enough regular structure that mathematics can model it.

01 · The core task

Predict the next token.

P(next token | all previous tokens)
The cat sat on the ___
mat
42%
floor
21%
chair
10%

The model ranks every possible next token by probability — then repeats this, one token at a time, to generate a full response.

02 · Tokens

Language is broken into tokens.

The cat sat on the mat.
The464
cat3797
sat3332
on319
the262
mat.2603

The exact numbers aren't meaningful by themselves — they're identifiers the model uses to look up a richer representation for each token.

03 · Embeddings

Tokens become vectors.

E(t) = x, where x ∈ ℝd
cat =
[0.72, −0.13, 0.91, 0.24, ...]

Related concepts land near each other in this space: distance(cat, dog) < distance(cat, democracy) — not from a stored definition, but from patterns learned across thousands of dimensions.

04 · Attention

Context changes meaning.

I deposited money at the bank.
We sat on the river bank.
Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V

A Transformer calculates which other tokens are most relevant when interpreting a particular token. Different context, different meaning — same word.

05 · Grammar

Grammar can be learned as probability.

She is walking.
He is running.
Ted is teaching.
"She is walking"
high
"She are walking"
low

No grammar rulebook required. Training adjusts the model so common, grammatical patterns receive far higher probability than unlikely ones.

06 · Distributed meaning

Meaning is spread across the network.

Training changes a very large number of parameters together. "Paris is the capital of France" isn't stored in one slot — it's distributed across relationships between many concepts.

07 · Training

Training is mathematical optimization.

The dog chased the ball
Loss: L = −log P(correct token)
high → shrinks as P(ball) grows
θ_new = θ_old − η∇θL

In plain language: identify which settings contributed to the error, nudge them slightly, repeat across an enormous number of examples.

08 · Putting it together

The whole pipeline.

Language
↓
Tokens → Vectors / embeddings
↓
Attention + context → Probability
↓
Generated language

fθ(x₁, x₂, ..., xₙ) → P(xₙ₊₁) — previous tokens in, a probability distribution over the next token out.

09 · The caveat

Does this mean language IS mathematics?

Language

Grammar, meaning, ambiguity, metaphor, analogy, emotion, culture, pragmatics, knowledge of the world.

Mathematics

The tool an LLM uses to represent and model patterns within that system — not a translation of meaning itself.

Language has enough regular structure that mathematics can model it.
Key takeaways

Language can be represented mathematically at several levels.

  • Tokens turn text into discrete units.
  • Embeddings turn tokens into vectors.
  • Attention mathematically represents context and relationships.
  • Probability ranks possible continuations.
  • Optimization changes billions of parameters so predictions improve.
  • Complex linguistic behavior emerges from these repeated operations.
An LLM is a machine that models the structure of language using geometry, probability, and optimization.
