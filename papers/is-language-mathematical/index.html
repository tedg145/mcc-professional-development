Is Language Mathematical?

How Large Language Models Represent Language with Mathematics

Ted Gonzalez, JD/MBA
Interactive version →
Central idea: Human language is not literally mathematics, but it has enough regular structure that mathematics can model it. An LLM converts language into numbers, learns relationships among those numbers, and uses those relationships to predict and generate language.

The Core Mathematical Task

At its most basic level, a large language model is trained to estimate the probability of the next token given the tokens that came before it. A token may be a word, part of a word, punctuation, or another small piece of text.

P(next token | all previous tokens)

For example, after the phrase “The cat sat on the ___,” the model might assign different probabilities to possible next tokens:

P(mat) = 0.42    P(floor) = 0.21    P(chair) = 0.10

The model then uses these probability distributions repeatedly, one token at a time, to generate a response.

1. Language Is Broken into Tokens

An LLM does not directly “see” a sentence the way a person does. The sentence is first divided into tokens. A sentence such as:

The cat sat on the mat.

might be represented internally as a sequence of token identifiers:

[t₁, t₂, t₃, t₄, t₅, t₆] → [464, 3797, 3332, 319, 262, 2603]

The exact token numbers are not meaningful by themselves. They function as identifiers that allow the model to look up a richer numerical representation for each token.

2. Tokens Become Vectors

Each token is converted into an embedding: a vector, or ordered list of numbers, in a high-dimensional mathematical space. Conceptually, a token such as “cat” might be represented like this:

cat = [0.72, −0.13, 0.91, 0.24, …]

More generally:

E(t) = x where x ∈ ℝᵈ

Here, E is the embedding function and d is the number of dimensions. In a modern LLM, the vector can have thousands of dimensions.

Related concepts often develop related numerical representations. In a simplified conceptual example:

distance(cat, dog) < distance(cat, democracy)

This does not mean the model has a dictionary definition stored inside the vector. Instead, meaning emerges from patterns of relationships across many dimensions.

3. Context Changes Meaning

Words can have different meanings depending on context. Consider these two sentences:

  • I deposited money at the bank.

  • We sat on the river bank.

The token “bank” begins with a token identity, but its internal representation changes as the model processes the surrounding words. Conceptually:

bank_money ≠ bank_river

A Transformer handles much of this contextual reasoning through a mechanism called attention.

Attention(Q, K, V) = softmax((QKᵀ) / √dₖ)V

Although the equation looks technical, the basic idea is simple: the model calculates which other tokens are most relevant when interpreting a particular token. In the first sentence, “money” and “deposited” help determine the meaning of “bank.” In the second, “river” provides the crucial context.

4. Grammar Can Be Learned as Probability

LLMs can learn grammatical patterns without being given a traditional grammar rulebook. During training, they encounter enormous numbers of examples such as:

  • She is walking.

  • He is running.

  • Ted is teaching.

Over time, training adjusts the model so that common grammatical patterns receive higher probability than unlikely or ungrammatical ones. For example:

P(“She is walking”) > P(“She are walking”)

The model therefore learns a great deal of grammar as statistical structure: patterns that make some sequences of words much more probable than others.

5. Meaning Is Distributed Across the Network

Suppose the training data contains the fact “Paris is the capital of France.” An LLM does not necessarily store that exact sentence in a single database location. Instead, training changes a very large number of parameters:

θ₁, θ₂, θ₃, …, θₙ

Together, those parameters encode relationships among concepts such as Paris, France, capital, city, and country. Meaning is therefore distributed across the network rather than stored in one obvious “slot.”

Paris ↔ France    Paris ↔ capital    France ↔ country

This distributed representation is one reason it is difficult to point to a single location inside an LLM and say, “This is where the concept of France is stored.”

6. Training Is Mathematical Optimization

Training repeatedly asks the model to predict the correct next token. If the correct continuation is “ball” in the sentence “The dog chased the ball,” but the model gives “ball” only a 10% probability, that prediction receives a relatively large penalty.

Loss: L = −log P(correct token)

If the model gives the correct token a much higher probability, the loss becomes smaller. The learning process then uses calculus and backpropagation to determine how the model’s parameters should change.

θ_new = θ_old − η∇θL

In plain language: identify which mathematical settings contributed to the error, adjust them slightly, and repeat the process across an enormous number of examples.

After enough repetitions, highly complex linguistic behavior emerges from these mathematical adjustments.

Putting the Process Together

A simplified view of the entire process is:

LANGUAGE → TOKENS → VECTORS / EMBEDDINGS

↓

ATTENTION + CONTEXT → PROBABILITY → NEXT-TOKEN PREDICTION

↓

GENERATED LANGUAGE

In an extremely simplified mathematical form, an LLM can be thought of as a large function:

fθ(x₁, x₂, …, xₙ) → P(xₙ₊₁)

The previous tokens are inputs. The model performs a vast number of matrix operations using its learned parameters, and the output is a probability distribution over possible next tokens.

Does This Mean Language Is Mathematics?

Not exactly. Language is a human symbolic and social system. It includes grammar, meaning, ambiguity, metaphor, analogy, emotion, culture, pragmatics, and knowledge of the world. Mathematics is the tool an LLM uses to represent and model patterns within that system.

Language has enough regular structure that mathematics can model it.

A useful way to describe modern LLMs is that they transform the structure of language into high-dimensional geometry and probability. The model does not translate each sentence into a traditional equation that states its meaning. Instead, it learns a mathematical space in which linguistic relationships can be represented and manipulated.

A Helpful Teaching Analogy

When a person prompts an LLM, they are not merely “talking to a computer.” Their words are being converted into numerical representations that alter how the model navigates a learned mathematical space of relationships.

This helps explain why small changes in wording, context, examples, or constraints can significantly change an LLM’s response: those changes alter the mathematical pattern presented to the model and therefore alter the probabilities of what comes next.

Key Takeaways

Large language models work because language can be represented mathematically at several levels:

  • Tokens turn text into discrete units.

  • Embeddings turn tokens into vectors.

  • Attention mathematically represents context and relationships.

  • Probability ranks possible continuations.

  • Optimization changes billions of parameters so predictions improve.

  • Complex linguistic behavior emerges from these repeated mathematical operations.

In one sentence: An LLM is a machine that models the structure of language using geometry, probability, and optimization.
