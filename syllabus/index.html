Where it goes

Pairs naturally with the Assignment Redesign material — after faculty have thought about the three redesign moves for a specific assignment, this is where they generate the syllabus-level language that backs it up, especially the AI Use Statement.

The AI Use section is the one worth slowing down on

The four options map to the red/yellow/green model already used elsewhere in this program. The "Tiered by assignment" option is the most work up front (it asks the instructor to label every assignment) but is also the most honest one — most real courses aren't purely one tier throughout.

Every category can be turned off

The toggle next to each section heading removes it from the assembled syllabus entirely — useful for department-mandated syllabi that already carry some of this language elsewhere and don't need it duplicated here.

Nothing here replaces official office language

The accessibility, Title IX, and resources sections are deliberately generic with bracketed placeholders. Point faculty to the actual current statement from Disability Services and the Title IX office — this tool gets them a well-structured draft to drop that language into, not a substitute for it.
